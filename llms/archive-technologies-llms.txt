# Archive Technologies

> Archive (Archive Technologies, Inc.) is an AI-powered creator and community marketing platform for e-commerce brands. Its public developer surface is the Archive API, a GraphQL API for programmatic access to creator, social profile, UGC, engagement, and collection data, plus an OAuth-protected remote MCP server for AI agents. Backed by Battery Ventures.

This llms.txt was generated by the API Evangelist enrichment pipeline from the API Evangelist catalog and Archive's public documentation (method: generated). Archive does not publish its own /llms.txt.

## API

- [Archive API (GraphQL)](https://app.archive.com/api/v2): Single POST endpoint. Auth: `Authorization: Bearer arch_live_...` plus a `WORKSPACE-ID` header. Cursor pagination (first/after, nodes/pageInfo). 5 requests/second per workspace.
- [API Documentation](https://api-docs.archive.com): Reference, concepts, guides, glossary, error handling.
- [Published GraphQL schema reference](https://app.archive.com/api/v2/docs): SpectaQL render of the live schema — 29 queries, 24 mutations, 135 types. Introspection is DISABLED in production, so this page (and the SDL below) is the schema of record.
- [GraphQL SDL](graphql/archive-technologies.graphql): the schema transcribed to SDL by API Evangelist from the reference above.
- [Roadmap + dated API changelog](https://api-docs.archive.com/roadmap): what shipped when, and what is coming (outbound webhooks are announced but NOT shipped).

## MCP

- [Archive MCP server](https://app.archive.com/api/v2/mcp): OAuth-protected (authorization_code + PKCE S256, scope `mcp`, dynamic client registration — no client id/secret needed). Discovery: /.well-known/oauth-protected-resource and /.well-known/oauth-authorization-server on app.archive.com.
- [MCP tool catalog](https://api-docs.archive.com/mcp): all 53 tools (29 read, 24 write), provider-published and kept in sync with the live server. Every tool maps 1:1 to a GraphQL operation and spends the same workspace credit budget.
- [Connecting an agent](https://api-docs.archive.com/mcp/connecting) and [creating a custom connector](https://api-docs.archive.com/mcp/custom-connector).
